# Memory Hole Lab

メモリーホール内の粒子輸送と表面帯電を調べるWindowsローカルアプリです。仕様書v0.5の固定形状Aを段階的に実装した開発版です。日本語React画面、FastAPI制御、独立した計算ワーカーを備えています。

## 起動

このPCでは依存関係と画面ビルドを準備済みです。`start.cmd`を実行すると、ローカルサーバーとブラウザを開きます。

```powershell
.\launch.ps1
```

画面は http://127.0.0.1:8765 です。CPU環境のみ準備する場合は`.\launch.ps1 -Cpu`を使い、画面の計算デバイスもCPUへ切り替えてください。画面ソースを変更した後は`-Build`を付けて再ビルドします。既に起動中の場合は同じ画面を開きます。

手動セットアップにはPython 3.12～3.13、uv、Node.js/npmが必要です。

```powershell
uv sync --extra gpu
Set-Location frontend
npm.cmd ci
npm.cmd run build
Set-Location ..
uv run --extra gpu python -m memory_hole
```

GPUグループはCuPyとCUDA 13のコンポーネントをプロジェクトの仮想環境に導入します。対応NVIDIAドライバが必要です。CPU専用の環境は`uv sync`で準備できます。

## 最初の操作

1. 設定画面でChannel径、膜厚、dummy個数・径・間隔を編集します。金属をクリックすると、そのdummyの距離を個別に変更できます。中心距離、xy座標による配置にも対応します。
2. 形状検査が通ったら、帯電なし・指定電荷・自己無撞着帯電を選びます。接触・重複・未接続・領域外の形状は実行できません。
3. 入口のイオン種と電子流束、波形、数値条件を設定します。全設定JSONから半径プロファイル、漏れ時間、反射・中性化・二次電子係数、乱数シードも編集できます。
4. 計算を開始し、場と軌道、表面電荷、衝突統計を確認します。帯電更新ごとに表示時刻を選択できます。
5. 完了ジョブを比較画面で選ぶと、底部到達率と条件付き95%区間、平均エネルギー、底部重心を比較できます。

寸法掃引は値リストを指定します。たとえば`geometry.gap_nm`に`50,100,150`を入力します。APIでは最大3寸法の直積を64ケースまで実行できます。特定dummyの掃引は、個別設定を作成してから`geometry.dummies.0.gap_nm`などを指定します。

各ジョブは開始時の設定を固定します。実行中の編集は別ジョブに適用します。停止時は完了済みの帯電更新と乱数状態を保存し、途中の更新は同じ乱数から再計算します。形状・条件・コード版の異なるチェックポイントは再開できません。

## 電場・粒子のアニメーション

「場と軌道」で結果ジョブを選び、再生モードを切り替えます。確認用の「アニメーション検証 · 時刻付きイオン・電子 · GPU」ジョブを準備しています。

- **帯電の時間変化**：保存済みの帯電状態を順に表示します。電位・電場・表面電荷の表示を切り替えられ、電場はRF位相0°です。1×は1保存時刻/秒です。保存時刻が1点の場合は再生できません。
- **粒子の飛行**：新しい計算では各保存時刻の代表飛行区間を、保存した経過時刻に沿ってns単位で再生します。イオンは橙、電子は緑です。軌道のRF位相を選ぶと、その軌道を計算した更新前の凍結電場と表面電荷を表示します。計算場の帯電時刻は操作欄に表示します。
- **再生操作**：再生・一時停止、先頭へ戻る、スライダー、0.25～4×の速度、繰り返しに対応します。粒子は1×で全表示時間を約6秒に引き伸ばします。再生中も3Dカメラを回転・拡大でき、時刻や表示レイヤーを変えても視点を保持します。

古い計算には軌道点の経過時刻がありません。この場合は経路上の位置を0～100%で再生し、「実時間ではありません」と表示します。既存ファイルへ時刻を推測して追記しません。代表軌道がないジョブは粒子再生を無効にします。

表示粒子を増やすには、設定画面の「実行条件」→「アニメーション用の代表軌道数」を変更して再計算します。既定は12本、上限は100本、0本では軌道を保存しません。例えば60本なら、イオン1種と電子へ各30本を配分します。これは保存する飛行区間数の上限で、未追跡の粒子などにより保存数が少なくなる場合があります。粒子再生では選択したRF位相の軌道だけを表示するため、画面の表示数は保存合計より少なくなる場合があります。全設定JSONでは`numerics.representative_trajectories`が同じ設定です。「サンプル数 / 種 / 更新」は計算統計用であり、表示数の指定には使いません。

全粒子を表示する機能ではありません。新しい計算は指定した代表軌道数を種ごとに配分し、帯電更新ごとに選び直します。代表飛行区間は表示上の共通の飛行時刻で再生し、保存点間の位置を補間します。粒子の実際の入射頻度や表示数から到達率を読み取りません。RF位相は飛行中固定で、RF時間依存ソルバーを追加したものではありません。色の範囲は各表示状態で自動調整し、凡例に実数値と単位を表示します。

時刻付き軌道と対応する電場・表面電荷はJSONおよびHDF5へ保存します。HDF5の`trajectory_times/`は秒、`trajectory_fields/`は表示用に間引いた場で、`time_series/`にも保存時刻ごとの軌道と対応場を含めます。チェックポイントの保存・再開とCPU/GPUの軌道時刻一致を回帰テストで確認しました。ブラウザで再生・停止・シーク・速度・終了・視点保持・旧データ・空軌道・読込中のジョブ切替・スマートフォン表示を確認し、結果は`data/qa/animation_check.json`と`data/qa/animation_ui_check.json`に保存しています。

## 提供されたIAEDFデータ

`sample-20mTorr.npz`と`sample-20mTorr.json`は変更していません。両ファイル内部の圧力は**10 mTorr**であり、ファイル名とは異なります。内部値を採用した検証ケースを初期設定にしています。

- p0の30万粒子から299,566到達粒子を選択。エネルギー・投影角・到達RF位相を同じ粒子インデックスで保持します。
- 指定ウェハ波形は`−170 + 158 sin(位相) V`、周波数13.56 MHzです。NPZの`V_e`とJSONの正弦波設定を照合します。
- 速度3成分は未保存です。面外速度をゼロとする近似で読み込みます。この近似は3D極角分布の再現ではありません。
- イオン絶対流束は密度×Bohm速度×到達割合による**推定**です。規格化IAEDFを絶対流束へ読み替えていません。上流の粒子重み・コレクタ面積との照合は未完了です。
- 電子は同じ温度・密度・`V_p`・`V_e`を使い、位相ごとのBoltzmann減衰と法線速度で重み付けした熱分布から生成します。実測電子分布ではありません。
- 評価面はCarbon上面z=0です。入口面のFEM電位をウェハ波形に拘束し、既に含まれるシース加速を追加しません。入口上方のフリンジ輸送の評価には、対応する上流コレクタのデータが必要です。

取込済みデータは`data/distributions/`、初期設定は`data/preset.json`、条件例は`examples/sample_10mtorr_case.json`にあります。例の分布IDはこのローカル環境の取込データを参照します。別環境ではペアを再取込してください。再生成は`uv run --extra gpu python scripts/import_sample.py`です。

画面からNPZと上流config.jsonを一緒に渡すと、1D正弦波ケースの波形・質量・温度・流束推定を更新します。分布だけを渡す場合は、現在の評価面・波形を記録します。旧NPZの投影角は、面外速度ゼロ近似を明示した場合だけ取り込めます。2D入力はコレクタのx範囲を必須とします。

## CSV入力契約

UTF-8 CSVの以下の形式に対応します。内部の法線は+z、xとyは接線です。

```csv
energy_ev,theta_deg,phi_deg,phase_deg,weight
100,2,30,90,1
120,4,60,180,2
```

`theta_deg`は法線からの3D極角、`phi_deg`は接線面内の方位です。速度を直接入力する場合は`vx_m_s,vy_m_s,vz_m_s`を使い、`vz_m_s`を正にします。`phase_deg`と`weight`は任意です。

相関ビン形式は`energy_low_ev,energy_high_ev,theta_low_deg,theta_high_deg,probability`です。確率を正規化してビンを選び、ビン内のエネルギー・角度は一様、方位は一様として生成します。密度CSVを自動的に確率と解釈しません。

## 数値モデルと保存

Gmshの境界適合四面体と一次FEMで、気相とSiO₂をまとめて倍精度で解きます。誘電率は材料ごとに設定し、露出SiO₂界面の電荷を弱形式の表面項へ一度だけ加えます。Carbon・埋め込み金属・基板の内部は未知量から除外し、共通の指定電位を与えます。dummyに粒子開口を設けません。4900 pFは全ウェハの記録用容量で、局所電流からウェハ電位を求める計算には使いません。

固定形状のFEM行列と電位基底を再利用します。大きなメッシュではAMG前処理を使用します。CPU輸送はNumba、GPU輸送はCuPy RawKernelです。P1四面体内の一定電場で放物線軌道と各面の最初の交差を解き、材料界面で再積分します。最大ステップ・相互作用回数に達した粒子は未解決として残し、吸収には数えません。

代表粒子重みは絶対流束×注入面積×物理時間÷サンプル数です。粒子飛行時間刻みと帯電更新時間刻みを分けます。自己無撞着モードでは電位変化上限に応じて物理時間を短縮し、代表粒子重みも同じ比率で変更します。数値緩和係数を物理時間へ読み替えません。

`data/jobs/<ID>/`に次を保存します。

| ファイル | 内容 |
| --- | --- |
| config.json | 版付き入力設定 |
| status.json | ワーカーの進捗・状態 |
| results.h5 | SIメッシュ、場、表面電荷、衝突分布、保存時刻の場、代表軌道、メタ情報 |
| checkpoint.h5 | 表面電荷、累積統計、時間、乱数状態、形状・メッシュ・コードのハッシュ |
| preview.json | 画面向けの間引いた場と統計 |
| snapshots/ | 保存時刻ごとのHDF5と表示データ |

画面のCSV出力は表面パッチの座標・面積・電荷密度・種別衝突重みです。衝突エネルギー・角度の同時ヒストグラムと深さ・方位分布はHDF5へ保存します。場の表示はRF位相0°の節点値・気相ベクトルで、全軌道の保存は行いません。

メッシュ・境界試験は壁面電荷2×10⁻⁵ C/m²、ウェハ−100 V、生成100 eVイオンの固定場を使っています。電位差は、角と界面から離した共通評価点でウェハ電位を差し引いた電位のL2相対差です。小さい電位差の評価を−100 Vの共通オフセットで過小評価しないための定義です。メッシュは各条件で再生成されます。

独立シード区間はケース全体の出力からStudent t（自由度4）で計算しました。帯電刻みの比較は同じ5シードを対応させ、差の区間と基準値の比を評価しています。到達率とエネルギーは計算時間全体の集計で、最終時刻の瞬間値ではありません。電子の希少イベントに対する精度保証はできていません。20ケースの最大電荷保存残差は6.84×10⁻¹⁶、5000回の対照計算は7.16×10⁻¹⁶でした。

詳しい結果・入力・HDF5・チェックポイントは`data/qa/numerical_validation_20261001/`に保存しています。`unresolved_diagnostic.json`は粒子単体の追跡上限比較、`cutoff_control_5000.json`はケース全体の対照計算です。後者の`cutoff_control_5000/config.json`を画面で読み込むと高回数の対照条件を再現できます。提供ファイルの内部圧力10 mTorr、面外速度と絶対流束の近似は引き続き有効です。

仕様書A全体の受け入れは未完了です。軸対称の独立参照モード、周期外側境界、任意のRF波形、RF位相間で粒子を保持する時間依存輸送、適応的な統計精度制御、材料・種・エネルギー・角度の表形式相互作用は後続工程です。今回の試験範囲を超える収束・統計検証、電位と外側境界の収束、電子の統計精度、局所空間電荷の5%感度試験、実測校正も未完了です。気相断面積が未入力の場合は衝突省略の妥当性を判定しません。

現在の表面係数は未校正の定数です。反射は鏡面反射、中性化イオンの反射と法線方向の単一エネルギー二次電子を近似します。漏れは指定時間による指数緩和です。気相空間電荷、気相衝突、固体内の電荷輸送、未知ウェハ電位のESC回路は計算しません。凍結RF位相に対する飛行時間診断を結果に表示します。

画面の95%区間は固定電場の重み付きサンプルに対するWilson/Kish近似です。帯電との相関を含む予測区間ではありません。追加検証の独立シード区間は画面の区間と区別します。電子到達がゼロでも上限を表示します。平均エネルギー区間は十分な底部サンプル数での正規近似で、1サンプル以下では未定義です。形状発展Bや形状異常の発生頻度は扱いません。

開発サーバーは`127.0.0.1`だけにバインドします。APIの一覧は起動後の`/docs`で確認できます。ソースは`src/memory_hole/`、画面は`frontend/src/`、テストは`tests/`です。
